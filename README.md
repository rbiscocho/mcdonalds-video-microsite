# McDonald's Video Submission Microsite – Frontend Prototype

Modern, responsive HTML prototype for a reusable video contest platform.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Landing / Campaign Home page |
| `register.html` | Registration & Login |
| `submit.html` | Video upload form |
| `dashboard.html` | User "My Submissions" dashboard |
| `admin.html` | Admin moderation panel |

## How to View

Open any of the HTML files in a browser. They are fully self-contained (Tailwind CSS via CDN).

Recommended order:
1. `index.html` → Landing
2. `register.html` → Create account
3. `submit.html` → Upload video
4. `dashboard.html` → View submissions
5. `admin.html` → Moderation queue

## Design Notes

- Brand colors: McDonald's Red `#DA291C` + Golden Yellow `#FFC72C`
- Fully responsive (mobile → desktop)
- Re-skinnable: change the Tailwind color tokens at the top of each file
- Forms are interactive for demo purposes (no real backend)
